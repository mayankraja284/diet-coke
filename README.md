# Diet Coke — Interactive 3D Website (fan-made demo)

React + Vite + React Three Fiber + GSAP ScrollTrigger + Framer Motion.

    npm install
    npm run dev       # http://localhost:5173
    npm run build     # production build to /dist
    npm run preview

Frontend demo only: sample prices, simulated checkout, no payments. The can is a procedural 3D model with a
canvas-painted label (no official photography bundled). Not affiliated with The Coca-Cola Company.
